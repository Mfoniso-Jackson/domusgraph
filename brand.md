### Applied to `tailwind.config.ts`, not shadcn

This project predates shadcn/ui — it uses a hand-rolled component library (`components/ui.tsx`) with named Tailwind colors (`ink`, `slate`, `leaf`, `signal`, `paper`, `mist`) defined directly in `tailwind.config.ts`, not shadcn's `--background`/`--foreground` CSS variable system. The brand palette was applied there instead. Backup at `tailwind.config.ts.bak`.

**Important — hex, not `oklch()`, in the config.** Tailwind v3's `@apply` cannot resolve opacity modifiers (`border-slate/20`, `ring-signal/20`) on a raw `oklch()` string in `theme.extend.colors` — it throws a build error. The hex values above are the same colors, converted via the exact OKLCB→sRGB reference math (not an approximation), and are what's actually in the config.

**No dark mode.** The project has never had a dark mode (no `.dark` class usage, no theme toggle anywhere). Only light-mode tokens were derived. Adding dark mode is a separate, larger piece of work — flag it before assuming this palette covers it.

Previous palette was `ink #17201b / moss #385244 / leaf #5c8068 / clay #b25f45 / paper #f7f4ee / mist #e8eee9` (warm terracotta/moss). `clay` was renamed to `signal` and `moss` to `slate` project-wide (17 files) since keeping a color literally named "clay" while it's a blue-gray would be a naming smell.

## Tone and voice

**Use:** plain, concrete, factual language. "Approved" not "greenlit." Numbers and dates over vague claims ("200 properties tracked," not "hundreds of homes"). Say what's verified and what isn't — this is a trust product, so honesty about data completeness matters more than polish (see the homepage's honest empty-state copy, or the Terms page's dispute process).

**Avoid:** hype words ("revolutionary," "game-changing"), vague reassurance ("don't worry," "trust us"), and anything that overstates what's actually verified. Never imply a review is confirmed fact — it's a structured account of one person's experience.

**Voice example:** "Landlord was responsive to a heating issue within 48 hours. Deposit returned in full, no disputes." — specific, factual, no adjectives doing the work that data should do.

## Usage dos and don'ts

**Do:**
- Use the named Tailwind colors (`text-ink`, `bg-signal`, `border-slate/15`) everywhere — never hardcode hex or rgba in components.
- Use `signal` sparingly as the one accent color (CTAs, links, active states) — it's meant to read as *the* brand color, not one of several.
- Use `leaf` only for success/verified states — it's intentionally a fixed hue, separate from the brand-derived family.
- Keep `slate` for secondary text and borders (via opacity, e.g. `border-slate/15`), matching the existing pattern.

**Don't:**
- Don't introduce a second accent hue without updating this file — the whole point of "Verified Slate" is one restrained accent color, not a rainbow of badges.
- Don't add dark mode without first deriving proper dark-mode seeds (see the "No dark mode" note above) — do not just invert the light values.
- Don't reintroduce `clay`/`moss` as color names anywhere — they were deliberately renamed.
